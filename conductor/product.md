# Initial Concept

KidShow Scout is an existing React + TypeScript application that helps parents find age-appropriate TV shows using AI-driven safety assessments and a sophisticated data ingestion pipeline.

By default, the application presents a curated "toddler-first" experience, showing only shows appropriate for ages 3 months to 2 years released from 2017 onwards.



A "Power Search" feature allows users to bypass all default and active filters by typing in the search bar, enabling discovery of the entire library regardless of age or safety classification.
